# PayPilot — 2 minute 45 second demo script

## 0:00–0:15 — Introduction
"PayPilot is an agentic commerce assistant. It understands shopping intent, finds grounded product options, checks budgets and prepares a customer-approved PayPal Sandbox checkout."

## 0:15–0:45 — Product discovery
Type: `Find wireless headphones under $150`
Show the product cards, source labels, and explainable match details. Point out that DummyJSON results are sample catalog data.

## 0:45–1:15 — Agent orchestration
Show the activity trace:
- Shopping Agent
- Budget Agent
- Trust Agent
- Personalization Agent
- PayPilot Supervisor
Explain that specialist checks are deterministic components coordinated around the OpenAI shopping agent.

## 1:15–1:35 — Personalization
Show saved category/brand/budget preferences. Save them and run a new search. Show the Personalization Agent activity. Do not show private account credentials.

## 1:35–2:00 — Proposal and checkout
Add an eligible demo product to the proposal. Review item and total. Click checkout and show the PayPal Sandbox approval page.

## 2:00–2:25 — Buyer approval and confirmation
Use a PayPal Sandbox buyer account. Approve the test payment. Return to PayPilot and show the server-confirmed Sandbox capture and order confirmation.

## 2:25–2:45 — Operations and close
Show the operations dashboard and order/payment event. Close:
"PayPilot combines AI-guided discovery, budget and trust checks, and human-approved PayPal checkout."

## Recording checklist
- Keep the video under 3 minutes.
- Record the actual working app, not slides alone.
- Use a Sandbox buyer account only.
- Hide `.env`, API keys, passwords, email inboxes, and unrelated browser tabs.
- Avoid copyrighted music.
- Make the YouTube video publicly accessible or unlisted if the submission platform accepts it.
